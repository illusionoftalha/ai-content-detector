# 🤖 ai-content-detector
> Detect whether any text was written by a human or generated by AI — powered by Groq's free API.

---

## ✨ Features

- Analyzes text for AI vs. human authorship
- Returns a verdict, AI probability score, and confidence level
- Breaks down signals: what looks AI-generated vs. human-written
- Sentence-level scoring with per-line AI probability
- Supports `.txt`, `.docx`, piped stdin, or interactive paste
- Colorized terminal output with progress bars
- Free to use via [Groq API](https://console.groq.com/)

---

## ⚙️ Requirements

```bash
pip install groq
pip install python-docx   # only needed for .docx support
```

A free Groq API key is required. Get one at https://console.groq.com/

---

## 🔑 Setup

Open `ai_detector.py` and paste your key:

```python
GROQ_API_KEY = "your_key_here"
```

Or set it as an environment variable:

```bash
export GROQ_API_KEY=your_key_here   # Linux / macOS
set GROQ_API_KEY=your_key_here      # Windows
```

---

## 🚀 Usage

```bash
# Interactive mode — paste text in the terminal
python ai_detector.py

# Analyze a .txt file
python ai_detector.py essay.txt

# Analyze a Word document
python ai_detector.py report.docx

# Pipe text from stdin
echo "Some text here" | python ai_detector.py -
```

---

## 📊 Output

Each analysis returns:

| Field | Description |
|---|---|
| **Verdict** | `AI-Generated`, `Likely AI`, `Mixed`, `Likely Human`, or `Human-Written` |
| **AI Probability** | 0–100% likelihood the text is AI-generated |
| **Confidence** | How certain the model is in its verdict |
| **AI Signals** | Specific patterns that suggest AI authorship |
| **Human Signals** | Specific patterns that suggest human authorship |
| **Sentence Breakdown** | Per-sentence AI probability scores |
| **Summary** | 2–3 sentence explanation of the verdict |

## 🧠 Model

---

## 🐛 Troubleshooting

**`No API key found`**
→ Set `GROQ_API_KEY` in the script or as an environment variable.

**`ModuleNotFoundError: groq`**
→ Run `pip install groq`.

**`Error: model returned unexpected output`**
→ The model response wasn't valid JSON. Run again — this is rare.

**`.docx` not supported error**
→ Run `pip install python-docx`.

**Text too short warning**
→ Provide at least 50 characters for a meaningful analysis.
